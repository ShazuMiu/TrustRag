Okapi BM25 is a ranking function used by search engines to estimate how relevant a document is to a search query. It is based on the probabilistic relevance framework developed by Stephen Robertson, Karen Sparck Jones and others in the 1970s and 1980s. The name comes from the Okapi information retrieval system implemented at City University London.

BM25 scores a document using three ideas: term frequency, inverse document frequency and document length normalization. Term frequency saturates, so repeating a word many times gives diminishing returns. The parameter k1 controls this saturation and is usually chosen between 1.2 and 2.0. The parameter b controls length normalization and is commonly set to 0.75. Because BM25 matches exact words, it is strong at finding rare terms, names and numbers, but it cannot match synonyms or paraphrases. For this reason modern systems often combine BM25 with dense retrieval in a hybrid search.
